## 6. Technical Stack & Data Models

### System Architecture
* **Frontend / Mobile App:** Next.js 14 (Web Quiz) + React Native / Expo (iOS & Android).
* **Astrological Microservice:** Python 3.9+ with `pyswisseph` (Swiss Ephemeris using Lahiri Sidereal Ayanamsa).
* **Database & Auth:** Supabase (PostgreSQL with PostGIS for automatic latitude/longitude and timezone conversion).
* **AI Engine:** Google Gemini 1.5 Pro with prompt-caching containing:
  - Child's natal astrological JSON (Nakshatra, house lords, aspects).
  - Parent's natal astrological JSON.
  - Evidence-based developmental psychology and gentle parenting principles.
* **Print-on-Demand Automation:** Gelato / Prodigi API for automated global book printing and drop-shipping to US/UK/CA/AU/DE.
* **Child Privacy:** Compliant with **COPPA** (Children's Online Privacy Protection Act) and **GDPR-K**. No child photos or location telemetry stored; birth data is anonymized and encrypted at rest.
